# PLANS_2027

Models del Programa d'actuacions del 2027, un per espai, generats a partir del Pla estratègic de cada parc (carpeta `PLANS_2026`).

Nom dels fitxers: `<CODI_PARC>_Programa_actuacions_2027.xlsx`.

Cada model porta el Pla estratègic de l'espai amb indicadors i fites, desplegables d'objectius, eix calculat automàticament, validacions i avisos, i les actuacions del 2026 com a punt de partida.
