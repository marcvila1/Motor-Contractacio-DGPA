# PLANS_2026

Carpeta on es pugen els Excel dels Programes d'actuacions del 2026 de cada espai (`.xlsx`), amb el Pla estratègic a la pestanya **PLA ESTRATÈGIC**.

## Com anomenar els fitxers
`<CODI_PARC>_Programa_actuacions_2026.xlsx`, amb el codi que fa servir el Motor (PNAP, PNP, PNAE, PNCM, PNCC, PNMMBT, PNINA, PNINP, PNMS, PNZVG, PNDE, PCTF, PNAESM, RMM…).

Exemples: `PNAP_Programa_actuacions_2026.xlsx`, `PNP_Programa_actuacions_2026.xlsx`.

## Per a què serveixen
Són el punt de partida per generar el model del Pla d'acció del 2027 de cada parc (carpeta `PLANS_2027`): objectius, accions, indicadors i fites del Pla estratègic, i les actuacions del 2026 com a base per al 2027.
