# PLANS_ESTRATEGICS

Plans estratègics de cada espai natural protegit (`.xlsx`), tal com han quedat aprovats.

## Com anomenar els fitxers
`<CODI_PARC>_Pla_estrategic.xlsx`, amb el codi del Motor (PNAP, PNP, PNAE, PNCM, PNCC, PNMMBT, PNINA, PNINP, PNMS, PNZVG, PNDE, PCTF, PNAESM, RMM…).

Si un parc té una versió nova, afegiu-hi la data: `PNAP_Pla_estrategic_2026-10.xlsx`.

## Per a què serveixen
Són la font dels objectius operatius, les accions, els indicadors i les fites dels models del Programa d'actuacions del 2027 (carpeta `PLANS_2027`). Les actuacions del 2026 són a `PLANS_2026`.
